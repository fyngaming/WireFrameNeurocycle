# NeuroCycle — Blueprint & Wireframe Ekosistem

Repositori ini berisi rancangan desain UI/UX, arsitektur ekosistem, serta wireframe interaktif untuk **NeuroCycle** — platform pengelolaan sampah dan ekonomi sirkular skala luas (menghubungkan Masyarakat, UMKM, Bank Sampah, dan Korporasi).

---

## 📁 Struktur Berkas

- **`wireframe_interaktif.html`**  
  Walkthrough prototype interaktif 8 layar aplikasi berbasis Tailwind CSS dan Lucide Icons. Cukup buka berkas ini di browser modern untuk melihat dan menavigasi rancangan layar dan alur kerja.
  
- **`1_neurocycle_ui_ux_showcase.jpg`**  
  Visualisasi showcase desain antarmuka dan pengalaman pengguna (UI/UX).

- **`2_neurocycle_arsitektur_ekosistem.jpg`**  
  Diagram arsitektur ekosistem terintegrasi NeuroCycle.

- **`3_neurocycle_wireframe_blueprint_pro.jpg`**  
  Blueprint wireframe tingkat lanjut untuk alur aplikasi dan komponen visual.

---

## 🚀 Cara Menjalankan Wireframe Interaktif

1. Buka berkas `wireframe_interaktif.html` langsung menggunakan web browser apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
2. Gunakan kontrol navigasi (tombol *Sebelumnya* / *Selanjutnya*, tab navigasi, atau tombol angka) untuk menjelajahi layar dan penjelasan fitur.
